About me

I started coding because I thought hacking was cool, and I still do. That curiosity about how things work, and how they break, turned into a habit of fixing what doesn't work and building solutions for real problems.

I'm a student developer working across the full stack. I build interfaces with React and Flutter, and back ends with Node.js and Python. I care about writing clean, fast code and making products that feel easy to use from the first click. I'm also interested in security, and I'm learning how to build apps that are safer by design.

I'm a quick learner who picks up new tools by building with them. I use AI as a learning partner and productivity tool, it helps me understand unfamiliar concepts, debug faster, and explore different approaches. I always review, test, and make sure I understand the code before it goes into a project.

I'm always looking for chances to learn, contribute, and grow alongside a team.
